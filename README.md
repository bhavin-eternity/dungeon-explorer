# Dungeon Explorer

A small terminal-based dungeon adventure game written in C.

## Features

- Explore a grid-based dungeon
- Collect treasure
- Avoid walls and traps
- Find the exit to win

## Requirements

- GCC
- Make

## Build and Run

```bash
make
./dungeon-explorer


Controls
- W: Move up
- A: Move left
- S: Move down
- D: Move right
- Q: Quit
